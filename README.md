# FinTracker

FinTracker is a personal finance tracking web application that helps users manage income and expenses, visualize spending patterns, and maintain a clear overview of their financial activity.

## Features
- User authentication using Firebase (Email/Password and Google Sign-In)
- Add, view, and manage income and expense transactions
- Real-time balance, total income, and total expense calculation
- Interactive transaction table with search, filter, sort, CSV import/export
- Line chart visualization for income and expenses over time
- Secure cloud data storage using Firebase Firestore

## Tech Stack
- React (Vite)
- Firebase Authentication & Firestore
- Ant Design (UI components)
- Chart.js (Data visualization)
- PapaParse (CSV import/export)

## Project Status

The project is functionally complete with authentication, transaction management, balance calculation, data visualization, and CSV import/export.
Future enhancements may include advanced analytics, monthly summaries, and improved chart insights.
